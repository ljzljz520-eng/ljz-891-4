# 课程软件授权核验站

面向学校/培训机构的课程软件授权核验系统：师生凭「账号 + 授权码」自助核验授权信息；管理员可在后台开通授权、停用账号、管理课程产品。

**零第三方依赖**：仅使用 Node.js（≥18）内置模块实现，数据以 JSON 文件原子写入持久化，无需安装数据库、无需 `npm install`，断网环境也能运行。

## 快速开始

```bash
node server.js
# 或 npm start
```

- 师生查询页：http://localhost:3000/
- 管理后台：http://localhost:3000/admin.html
- 默认管理员：`admin` / `admin123`（首次登录后请尽快修改）

可通过环境变量 `PORT=8080 node server.js` 修改端口。

## 功能说明

### 师生端
- 输入账号 + 授权码，展示：授权课程（名称/版本）、有效期（开通时间、到期时间、剩余天数）、设备数量（已用/上限、进度条）。
- 授权码输入容错：不区分大小写、可省略连字符；字符表去除了易混的 0/O、1/I/L。
- 状态区分：**有效 / 15 天内即将到期 / 已到期 / 已停用**。
  - 已到期：展示授权明细 + 续费提示；
  - 已停用：只展示停用原因，不暴露课程明细。
- 查询失败时**不出现“系统错误”**，而是给出可能原因清单（输错、未开通、已停用、账号与授权码不匹配等），并提示联系管理员。
- 按 IP 限流（5 分钟 15 次）防爆破；网络异常同样给出友好提示。

### 管理后台
- 令牌登录（PBKDF2-SHA256 口令哈希 + 随机盐，会话 8 小时有效），登录限流。
- **授权管理**：开通授权（自动/自定义授权码、多选课程、设备上限、有效天数、开通时间、备注）、编辑（设备数、到期时间等）、停用（填写对用户可见的停用原因）/ 重新启用；支持按账号/姓名/授权码搜索、按状态与产品筛选、分页。
- **产品管理**：新增/编辑课程产品（名称、版本）、上架/下架；下架产品不可被新授权选择。
- **数据概览**：授权总数、有效、已到期、已停用统计。
- 重复账号开通、非法设备数/天数、授权码格式、空产品等均有服务端校验与中文提示。

## 目录结构

```
server.js        HTTP 服务、路由、鉴权、限流、业务接口
store.js         JSON 文件数据层（原子写入、种子数据、各实体操作）
crypto-util.js   口令哈希、会话令牌、授权码生成/归一化
public/          前端页面（index 查询页、admin 登录、dashboard 后台）
data/db.json     运行后自动生成的持久化数据
```

## 接口一览

- `POST /api/query` 公开授权核验
- `POST /api/admin/login` / `POST /api/admin/logout`
- `GET  /api/admin/stats`
- `GET/POST /api/admin/licenses`、`PATCH /api/admin/licenses/:id`、`POST .../:id/disable|enable`
- `GET/POST /api/admin/products`、`PATCH /api/admin/products/:id`

## 安全与部署说明

- 本系统适合校内/机构内部使用。若对公网开放，建议置于 Nginx 反向代理之后并启用 HTTPS。
- 数据文件 `data/db.json` 建议纳入定期备份；文件损坏时系统会自动备份损坏文件并重建，保证可用。
- 生产规模较大（万级授权以上）时，可将 `store.js` 替换为 SQLite/关系数据库实现，接口层无需改动。
